# UI 性能测量记录

采集日期：2026-10-17。测试使用模拟数据，不连接真实代理内核。

本记录和 [有效测量数据](results.json) 随代码提交，保留在文档目录，清理 `target/` 或 `ui/build/` 不影响归档。原日志文件名保存在数据中，便于对应之前的性能报告。归档提取了测量行的完整指标，数值未改动；临时调试服务地址和启动输出未收录。

## 环境与范围

- macOS 27.0.1、Mac16,10、arm64，Flutter 3.47.6、Dart 3.13.5。
- 使用 macOS Profile 构建，按对应入口的默认布局运行。
- 以下数据是本机特定场景的测量结果，不代表其他设备、数据规模或 Release 模式的固定耗时。
- 首帧／布局等待包含调度等待，与 `FrameTiming.buildDuration` 的帧构建耗时是不同指标，不能混用或相加。

## 测量结果

| 场景 | 数据和动作 | 指标 | 优化前 | 优化后 |
| --- | --- | --- | --- | --- |
| 隐藏页面收到推送 | 5000 条隧道、500 条日志，50 次推送 | 帧构建中位数 | 8.612 毫秒 | 0.146 毫秒 |
| 隐藏页面收到推送 | 同上 | 日志列表读取次数 | 50 | 0 |
| 访问记录远距离滚动 | 5000 行，底部／顶部／底部共 3 次跳跃 | 布局等待中位数 | 1686.248 毫秒 | 9.359 毫秒 |
| 访问记录远距离滚动 | 同上 | 累计构建行数 | 14937 | 60 |
| 访问记录切回实时隧道 | 各 5000 条，隧道滚动偏移 0，切换 3 次 | 首帧等待中位数 | 27.697 毫秒 | 13.591 毫秒 |
| 访问记录切回实时隧道 | 各 5000 条，隧道滚动偏移 200000，切换 3 次 | 首帧等待中位数 | 8212.576 毫秒 | 21.300 毫秒 |
| 访问记录切回实时隧道 | 同上 | 帧构建中位数 | 2714.037 毫秒 | 15.174 毫秒 |
| 访问记录切回实时隧道 | 同上 | 累计构建行数 | 10956 | 63 |

后台页面优化对应 `f227c31`，改为隐藏时解除高频显示订阅。访问记录滚动比较来自 `c344fc6` 中同一个基准入口内的两种行高策略，不是两份完整应用的对比。页签切换以 `8802da4` 的页面实现为基线，优化对应 `4236923`，采用页签状态保留、固定行高和隐藏时停止刷新／分页。

## 测量入口与复测

入口均位于 `ui/test/fixtures/`：

- [hidden_pages_benchmark.dart](../../../test/fixtures/hidden_pages_benchmark.dart)：模拟隐藏页面收到 50 次推送。
- [access_scroll_benchmark.dart](../../../test/fixtures/access_scroll_benchmark.dart)：在同一进程中比较逐行测量和固定行高。
- [tunnel_switch_benchmark.dart](../../../test/fixtures/tunnel_switch_benchmark.dart)：分别测量列表顶部和深处的页签切换。

从项目根目录加载本机构建工具配置，再选择入口构建。例如：

```sh
. scripts/build-tools.sh
load_build_tools "$PWD"
cd ui
"$FLUTTER" build macos --profile -t test/fixtures/tunnel_switch_benchmark.dart
build/macos/Build/Products/Profile/network_ui.app/Contents/MacOS/network_ui
```

入口运行后输出测量数据并自行退出。性能采集应单独运行，避免同时执行测试、构建或另一轮基准测量。比较旧实现时需使用对应页面代码，保留相同测量入口、设备和数据规模；当前代码直接运行得到的是当前实现的结果。

后续临时输出仍可写入构建目录；需要长期引用的最终性能对比，应记录测试条件、测量入口及有效原始指标，归档到本目录所属的 `performance/` 日期子目录并提交，不将构建目录内的日志作为唯一证据。
