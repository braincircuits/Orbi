# macOS 风格桌面 UI 规范

按用户明确要求，参考 Build macOS Apps 的侧栏、工具栏与分组设置规范，以 Flutter Material 基础组件实现 macOS 风格；macOS、Windows、Linux 使用同一套页面、主题和交互方式。使用侧边导航、紧凑工具栏、分层状态面板和侧边编辑。各平台复用同一套实现，不按系统分叉控件。

## 组件与主题

主主题位于 `lib/ui/desktop_theme.dart`。页面优先复用 Flutter 官方 NavigationDrawer、NavigationRail、Card、SegmentedButton、菜单、按钮、输入框、弹窗和滚动条；现有 DesktopWidgets 仅组合重复的表单与内容结构。不要添加 macos_ui、Fluent UI 或 Cupertino 视觉组件。

设置面板提供跟随系统、浅色和深色三种主题，默认跟随系统。选择后立即生效并自动写入本机 `appearance.json`，无需应用代理配置；保存失败恢复原选项并提示重试。明暗主题使用相同结构、排版和控件尺寸。通过 ThemeData 的组件主题统一 macOS 风格桌面视觉，不覆盖真实 TargetPlatform；保留宿主文本编辑、选择和键盘行为。平台提供窗口、文件选择和系统菜单等宿主能力；不得依据操作系统改变共享页面风格。

| 日志、地址与规则 | Roboto Mono；中文使用共享系统字体与内置 Noto Sans SC 回退 |

| 间距 | 以 8 px 为主要节奏，4 px 用于紧凑细节；表单允许按信息密度微调 |

| 下拉菜单 | 官方 DropdownMenu，只读选择；菜单最大宽度 320 px、每项 36 px、圆角 8 px，细边框和轻阴影；当前选项使用蓝灰色勾选，悬停和键盘焦点使用淡色背景 |
| 操作菜单 | 官方 MenuAnchor 与选择菜单复用同一表面、阴影和圆角；隧道路由菜单最小宽度 192 px、每项 36 px，“恢复自动”与切换操作用轻分隔线区分 |

共享内容区由 Flutter 绘制。macOS 侧栏使用 AppKit 的 NSVisualEffectView 侧栏材质与 behindWindow 混合，真实模糊窗口后方背景；Flutter 只让侧栏透底，正文保持不透明。材质随窗口激活状态及系统“减少透明度”设置调整，外观跟随应用当前明暗主题；不覆盖整个窗口的 appearance，以免阻断跟随系统模式。其他宿主使用共享侧栏底色，控件和页面结构不变。系统窗口按钮、拖动、菜单和快捷键沿用现有宿主能力。

字体来源、授权和校验信息见 `assets/fonts/README.md`。不要引入运行时网络字体加载。

## 视觉层次

不要把 Material 3 等同于默认主题外观。桌面页面使用中性灰背景和独立内容面板，侧栏使用更深一级的灰底、轻量选中行与蓝色图标，并按网络、工具分组。概览分为中性底色服务控制区、四项指标和全宽趋势面板；用字号、留白和背景区分主次，避免叠加无关装饰。连接集合顶部显示当前已应用连接，卡片选中态同时使用浅强调底色和边框。

## 窗口与交互

- 正文标题和代理状态共用 56 px 高的单行顶栏。品牌始终位于侧栏窗口按钮下方。顶栏空白处支持原生窗口拖动，操作区不触发拖动。macOS 保留真实窗口按钮，固定居中于顶栏；使用父视图顶部约束，避免缩放后裁切，隐藏系统重复标题和额外工具栏。
- 窗口宽度达到 760 px 时使用 184 px 宽的 NavigationDrawer，否则使用 150 px 宽侧栏；34 px 高导航项以 32 px 高的圆角灰底标明当前页面。底部提供独立设置入口。
- 窄窗口正文水平边距 18 px，宽窗口 28 px。表单可用宽度小于 420 px 时标签放在输入框上方，避免压缩编辑区域。正文过长时滚动，保留页面位置和编辑草稿。
- 保留 Material 的悬停、按压、禁用和焦点状态，关闭扩散水波纹；普通次级按钮使用中性文字、细描边和面板底色。概览、配置、规则和诊断页面隐藏外侧滚动条，保留滚轮、触控板和键盘滚动；日志和菜单内的滚动条保留，鼠标悬停或拖动时增强。图标操作提供 Tooltip。
- 所有按钮、选择控件和输入框支持 Tab / Shift+Tab 导航，按侧栏、顶栏、页面内部的组件顺序遍历，避免跨栏跳转。输入框保留 Flutter 的宿主编辑快捷键。
- 初始化或提交期间同时禁用正文和设置表单的鼠标输入与键盘焦点，结束后保留原有草稿。标题栏拖动范围随页面、窗口、文字缩放和状态文字变化重新计算，不覆盖操作区。
- 状态提示统一使用中性面板、语义图标和文字，可主动关闭；错误提示保留较长阅读时间，长消息可滚动。窄窗口不超出边界；相同提示在显示期间不重复排队或延长时间，新提示替换当前提示，关闭后不继续播放历史消息。
- 尊重系统文字缩放。连接卡片、列表行高和定位偏移使用同一套缩放尺寸，空状态在高度不足时允许滚动，不通过裁切隐藏文字。
- 应用操作同时支持 Ctrl 和 Command：1～6 切换页面，逗号打开独立设置面板，Enter / S 应用并保存配置。快捷键与按钮调用同一个现有操作。
- 明暗切换、页面切换和窗口缩放不得触发业务配置写入，也不得重建内核连接。
- 编辑器“应用并保存”固定在底部，草稿和内核保存状态用文字明确提示。处理中保持禁用，应用失败或保存失败时保留醒目提示；只改变视觉，不改变现有应用及保存行为。
- 启动首帧显示概览，连接内核和自动启动期间显示明确状态与进度，不以空白区域替代页面；操作保持禁用，完成或失败后恢复操作。
- 导航顺序固定为概览、连接配置、活跃隧道、路由规则、连接诊断、运行日志，原生菜单与数字快捷键保持一致；诊断默认目标为 `www.google.com:443`。

## 范围与验证

UI 改造涉及展示与交互协调，复用现有视图模型、网络协议和内核 API；连接切换仅合并本次默认连接和版本，保留未应用的编辑草稿。共享页面不意味着原生宿主功能已经在三个系统完成接入；当前仓库仅有 macOS 宿主，Windows 和 Linux 原生打包另行处理。

静态分析和控件测试覆盖三种桌面 TargetPlatform、明暗主题、窗口缩放、表单草稿、键盘操作和已有业务回归。按需使用 `UI_PREVIEW_DIR=/临时预览目录 flutter test test/desktop_preview_test.dart` 导出应用字体的明暗预览；预览使用临时数据，不读取用户代理配置。

新增公共交互检查覆盖 720 × 540 窗口的 130% 文字缩放、错误提示关闭及处理中表单焦点隔离。三平台控件测试使用各自真实的 ThemeData.platform，不以固定平台掩盖差异。

## 连接配置卡片

- 采用已确认原型的灰蓝背景、白色或深灰面板、柔和选中态；连接卡片左上显示协议、右上显示绿色“使用中”，中间展示名称和服务端地址，底部分隔操作栏显示“当前连接”或“设为当前”及“编辑”；当前连接使用强调边框，待应用的新连接禁用切换。搜索、协议筛选和卡片／列表切换统一为 30 px 高度。
- 搜索按名称或服务端地址匹配，可叠加协议筛选；卡片与列表共用实际连接草稿，每批显示 12 项，滚动接近底部时增加显示数量，使用 Sliver 惰性构建，不生成模拟连接。
- “定位当前”清除筛选，加载并滚动到内核当前默认连接。点击卡片主体立即切换当前连接，底部“编辑”单独打开侧边编辑面板；列表行点击仍打开编辑。卡片主体、“设为当前”和编辑面板内的“设为默认连接”复用现有默认路由切换接口，由内核关闭旧代理隧道；切换保留编辑对象和未应用草稿，当前连接与切换过程中禁止重复切换。新连接必须先应用才能使用。
- 可用宽度达到 540 px 时在右侧显示 264 px 编辑面板（窗口宽度不超过 920 px 时为 230 px）；较窄时编辑面板排列在连接区下方。连接区和编辑表单独立滚动，编辑操作固定在面板底部。面板高度随窗口调整。
- 编辑沿用现有自动保留草稿机制；收起面板、切换页面和切换实际连接不会清空草稿。密码、TLS 和高级参数仍须应用配置；本地代理与内核运行环境放入独立设置面板；密码不在卡片展示，切换编辑对象时恢复隐藏。
- 撤销草稿和移除连接需要明确确认；当前实际使用连接不可移除。版本冲突继续使用现有内核快照同步规则，失败反馈和保存版本检查保持不变。


系统字体按用户确认优先还原原型，各系统实际可用字形可能略有差异；不按平台切换控件结构。预览测试可通过 `UI_PREVIEW_LATIN_FONT` 和 `UI_PREVIEW_CJK_FONT` 指定本机字体文件，核对系统字体效果，文件仅在测试进程读取，不复制进应用资产。

设置面板关闭时保留共享草稿；应用并保存会提交全部配置草稿，不单独提交某个面板。主页面使用 IndexedStack 保留搜索、协议筛选、显示数量、编辑器与滚动状态；实际内核请求仍由现有视图模型管理。

侧栏使用 Material ListTile 保留键盘与焦点能力，选中背景立即更新，与正文切换同步，避免内置目的地的半秒动画造成先后跳转感。虚拟网卡开关沿用 Material Switch 的交互，使用统一的紧凑尺寸、蓝色开启轨道和白色等大滑块，明暗主题及三个桌面平台保持相同结构。

访问记录在滚动距底部不足 120 px 时自动按游标加载下一页，记录不足一屏时继续加载，保留查询词和状态筛选；加载期间不重复请求，到末页停止。正常状态不显示手动加载按钮，加载失败保留现有记录并显示重试按钮；查询、刷新或切换筛选时回到列表顶部。实时隧道和访问记录不再单独展示连接名称，保留路由、传输协议和来源地址。

品牌始终位于侧栏窗口按钮下方；56 px 工具栏仅占正文列。864 × 642、1024 × 658 和 1120 × 780 窗口均检查明暗截图；窄窗口不再把品牌搬到顶栏。连接编辑器采用协议、端口双列表单和固定底部操作栏；列表模式提供列标题。


## 概览与网络状态

- 服务开关和模式分段按钮统一为 36 px 高，开关宽 90 px，三个模式各宽 64 px。两组右侧对齐；启停行可用宽度不足 430 px、模式行不足 480 px 时上下排列，控件仍靠右。停止使用错误语义实心色，开启使用主色实心底，文字对比度按明暗主题验证。

- 顶部显示服务运行状态与唯一的开启／停止操作，不再提供重启、断开会话或当前连接选择框。实际服务端地址和协议始终只读展开；连接修改和切换仍在连接配置页进行。
- 路由模式使用共享 SegmentedButton：规则、直连、全局（内部值 proxy）。规则模式保留已有目标规则和直连规则；直连与全局覆盖规则，但不清空规则。只作用于进入本地代理的流量，不修改操作系统代理。模式即时应用并保存，不提交或清空尚未应用的表单草稿。成功以选中态反馈，不弹成功提示；失败仍提示。切换期间保留防重复提交限制，路由页按钮外观和底栏文字保持稳定，不插入全局模式覆盖提示。
- 本地 HTTP 代理优先显示实际监听地址，停止时显示已应用配置，支持复制。状态区展示服务端连接、全部活跃隧道与等待隧道。
- 连接延迟由内核测量 HTTP/2 PING 或 QUIC RTT，显示检测时间。直连、停止、内核离线时不显示旧值；检测和网站响应耗时使用不同标签。
- 出口 IP 通过内核查询 ipwho.is，展示公网 IP、归属地、运营商、来源和更新时间，支持刷新和复制。无归属数据时显示未知；规则模式提示不同目标可能使用不同出口。
- 网络测试依次检测 GitHub、Google、YouTube，按实际模式展示 HTTPS 响应头耗时及可访问、HTTP 错误、超时、连接失败状态。每站最多 5 秒，不跟随重定向；允许取消并保留同一上下文中已完成的结果。
- 同一网络上下文刷新出口时，界面保留上次成功结果和更新时间，并显示“获取中…”；按钮预留加载文案宽度，IP 行保留复制按钮高度，避免刷新时布局跳动。刷新完成后显示新结果或失败信息。配置应用、模式切换、连接切换、启停、内核重连时，根据内核实例和 networkGeneration 丢弃过期结果；停止时禁用检测。测试不会自动切换路由或回退直连。
- 当前连接与出口信息并排时，正文和页脚分别共用行高；长地址、运营商换行、文字缩放和窗口调整后，两张卡片的分隔线与外框底部保持对齐。窄窗口改为上下排列，各卡片按内容确定高度。
- 信息按服务控制、隧道状态、当前连接、出口 IP、网络测试分层。窄窗口将并排详情上下排列，保持桌面主题、键盘操作、明暗布局和三平台一致性。

- 首次进入概览或内核实例、连接状态变化后自动更新一次连接延迟和出口 IP；窗口返回前台及页面切换不重新检测。等待初始化与当前操作完成，复用正在进行的同类检测；失败由用户手动重试。停止时等待下次开启，直连跳过服务端延迟；网站测速仍由用户手动触发。概览检测结果只在对应区域展示，连接诊断记录仅显示手动连接测试和路由查询。
- 连接配置的卡片视图初次打开不展开编辑侧栏；点击编辑、添加或定位后再展开，收起不丢弃草稿。

## 概览流量趋势

- 概览采用四项独立指标面板与全宽趋势图，可用宽度不足 680 px 时指标改为两列：发送速率、接收速率、活跃隧道、连接延迟。速率下方显示本次启动累计量；等待数量并入隧道查看入口，服务端状态放入当前连接详情。连接与出口信息在可用宽度达到 760 px 时并排。
- 统计数据仅取自内核 `traffic` 能力，使用十进制 B／KB／MB／GB 单位；曲线和数字覆盖代理与直连业务。每秒采样，保留五分钟，可切换一／五分钟、显示或隐藏发送与接收曲线，并通过鼠标或点击读取同一时刻的两条曲线。
- 重复样本去重，内核快照补齐断线历史；相邻采样超过 2.5 秒时不跨空档连线。内核离线时数字显示未知，停止后速率为零并保留历史；新启动会话开始新的实时窗口，旧采样长期写入 SQLite；内核重开时恢复最近会话记录。不会在 UI 中生成或推算缺失样本。
- 延迟检测、出口刷新、网站测试／取消及模式切换保留原有行为。本地入口仍为 HTTP 代理，不新增本地演示模式或系统代理开关。
- 当前 SQLite 内核的配置请求原子提交，成功响应即代表配置已落盘；客户端不再调用独立保存接口，也不显示“内核更改尚未保存”。请求失败保留编辑草稿。


## 长期历史记录

- 流量趋势下方的“历史流量”可按本地日期查询已保存采样，并逐页查看更早窗口。一张图只显示一个启动会话，跨会话不连线；数据范围均来自数据库，实时概览仍为一／五分钟。
- 活跃隧道页增加“实时隧道／访问记录”切换。访问记录按目标域名、IP 或端口搜索，分页显示时间、来源、方法、路由、协议、连接名称和建立结果，长期保留。
- “已建立连接”只说明 TCP 或代理隧道建立，不表示网站请求成功；不记录路径、查询参数、请求头或正文。内核未连接时禁用查询，错误可重试，数据库写入失败或队列丢弃在概览提示。


## 路由规则操作

- 页面沿用桌面主题，顶部为路由模式、已应用默认代理与路由查询；“直连规则／指定目标”常驻切换。移除顶栏通用“应用配置”，直连规则的应用与放弃按钮固定在页面底部。
- 直连列表按原文行定位，备注优先显示行尾注释，其次显示注释分段；切换列表与批量编辑不重排或重写原文。只在用户新增、编辑、删除时更新相应文本，规则校验和匹配交给内核。
- 列表按需构建，模式、查询、筛选及内联编辑表单随内容滚动；窄窗口将行内操作放到目标信息下方，底部按钮可换行。编辑远处条目后定位到编辑表单。
- 路由页的快捷键和原生应用命令只提交直连规则，其他页面维持完整配置应用语义。文件不再作为持续规则来源，仅通过预览导入草稿。
- 精确目标编辑只改变直连／代理，避免先删除再添加产生临时路由变化；移除指定规则立即生效。查询使用当前内核快照，显示命中类别而非未提供的具体命中条目；旧配置上的异步结果标记过期。
